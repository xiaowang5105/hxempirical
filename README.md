# hxempirical

Stata 实证工作台（HX Empirical Workbench）。

当前发布版本：0.9.7。

## 一行安装

优先使用 GitHub 的 `github.com/.../raw/...` 地址：

```stata
net install hxempirical, from("https://github.com/xiaowang5105/hxempirical/raw/main/") replace
```

如果你的 Stata 能直接访问 `raw.githubusercontent.com`，也可以使用：

```stata
net install hxempirical, from("https://raw.githubusercontent.com/xiaowang5105/hxempirical/main/") replace
```

## 启动

```stata
hxempirical
```

支持 Stata 17 及以上版本。
