# 研究项目

在工作台顶部点击“研究项目”，选择“新建项目”。项目以创建时的当前内存数据为起点，保存为 `.hxproj` 文件；旁边的 `hx-assets-*` 目录保存数据和模型快照。移动或分享时请一起复制。

## 保存和继续

每个完成的工作台步骤自动写入 `.hxproj.recovery`（含当前数据），未完成的命令不进入恢复点。再次打开原 `.hxproj` 时会提示较新的恢复点。手动保存保留上一份可读项目为 `.hxproj.bak`；主文件损坏时可尝试打开备份。移动时请同时携带两个旁文件与资源目录。自动快照的耗时随数据大小增加。

当前快照只支持单 frame；存在额外 frame 时停止保存和恢复，原数据保持不变。请先分别保存额外 frame，再关闭它们；完整 frameset 和链接依赖仍需自行管理。恢复时如随机数状态或数据读取失败，会恢复原数据、结果和随机数状态。

保存检查所有模型的 `.ster/.tsv/.sample`；资源缺失时报告具体文件名。资源路径拒绝符号链接和 junction，包括尚未创建的新目标。单项目最多 10,000 步、64 MB 日志，保存前检查上限。写入要求文件系统支持原子替换，临时文件同步后再替换；不支持时保留旧文件并报错。文件同步无法保证所有存储设备的断电恢复行为，备份需要随项目保留。

失败写入只清理本次生成的资源；新快照提交成功后，只清理已知旧快照中不再被主项目、备份和恢复点引用的文件。无法验证引用时保留文件，避免误删。

“保存项目和当前数据”会保存运行步骤、模型设置以及新的数据快照。打开项目时，用户确认后载入上次保存的数据并恢复随机数状态；历史命令不会自动执行。“查看步骤 / 恢复模型设置”可以查看每一步的命令、返回码和输出，恢复所选模型的界面设置。

关闭窗口或切换项目时，有未保存的步骤会提示保存。请在 Stata 退出前主动保存项目。项目步骤覆盖工作台记录的运行；在 Stata 原始命令窗口中手动执行的步骤，需要自行补入导出的脚本。

## 导出 do-file

面板向导与通用面板页自动执行的 `xtset` 会作为单独步骤先于估计命令记录，导出脚本按此顺序重跑。旧项目中此前漏记的声明无法自动补回，请核对面板 ID、时间变量并补入脚本。

新保存的 IV 设置包含内生变量、工具变量、估计方式、固定效应、面板/时间变量及通用权重。33/34 字段的旧设置仍可读取；旧记录未保存的角色需重新选择后保存。

导出脚本从项目初始数据快照开始，包含记录的命令和原始随机数状态。执行失败的步骤使用 `capture noisily` 保留，使脚本能够继续执行其后的已记录步骤。脚本中的数据路径为导出时的绝对路径，搬移项目后应重新导出。

外部数据文件、第三方命令及版本仍需保留。1.6.1 新记录的文件转换包含临时 frame 创建、实际导入、保存和清理步骤，后续载入单独记录。重放转换会使用 `save, replace` 重新生成指定输出 DTA，请执行前检查输出路径。界面转换中的临时文件发布保护属于工作台运行实现，导出的原生 Stata 脚本使用 Stata 保存命令。旧项目此前遗漏的转换步骤需要手动补齐；导出不会自动执行。

转换后载入统一确认替换当前数据，后台执行 `hxproject load`，失败恢复原数据和估计结果。此内部命令随安装包提供，重放载入步骤需要安装对应版本工作台。文件转换成功与载入成功分别报告；取消载入会保留已经转换的 DTA 文件。

每一步的项目输出保留前 64 KB；原始命令和参数完整保存。

## 模型比较

项目内成功运行的受支持回归会保存 `.ster` 估计结果、完整系数和标准误，以及逐观测 `e(sample)`。比较表按 M1、M2 等展示命令、N、R²、标准误类型及系数。完整命令保留固定效应、权重和样本条件。

样本一致性同时比较数据内容签名和逐观测样本标记。相同的 N 可以来自不同观测，因此不会仅凭 N 判断样本一致。

“导出共同样本重估 do-file”支持普通 `regress`、`areg`、`xtreg`、`reghdfe` 命令。脚本先验证当前保存的数据版本，再计算各模型样本的交集，保留原有 if / in / 权重和选项重估。每个重估模型都核对实际样本；固定效应单例删除等因素导致实际样本继续缩小时，脚本会停止，供研究者调整样本后重跑。含复杂前缀、宏或多行命令的模型需要手动指定共同样本。

## 测试与发布

普通 CI 编译全部 Java 模块并运行项目行为测试。`.github/workflows/stata-release.yml` 在版本标签或手动触发时运行真实 Stata 验收，要求维护者配置带 `Windows`、`stata` 标签的 self-hosted runner，并设置 `STATA_EXE`；该配置不会自动申请或安装 Stata 许可证。

本地运行全部真实测试：

```powershell
./tools/run_stata_tests.ps1 -StataExe 'D:\Stata\StataMP-64.exe' -KeepLogs -LogDirectory .build/stata-logs
```
